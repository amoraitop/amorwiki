# ΑμορWiki — Cloud ανάπτυξη (Render free tier)

Αυτός ο φάκελος περιέχει ό,τι χρειάζεται για να τρέχει το ΑμορWiki **πάντα** στο διαδίκτυο,
χωρίς να είναι ανοιχτό το λάπτοπ.

## Περιεχόμενα
- `amorwiki_server.py` — ο server (cloud-compatible: διαβάζει το `PORT` από το περιβάλλον)
- `books/` — τα 224 αρχεία βιβλίων (.md)
- `requirements.txt` — εξάρτηση (markdown)
- `Procfile` — εντολή εκκίνησης για Render

## Πώς λειτουργεί
Στο cloud, ο server βρίσκει τα βιβλία στον **δικό του** φάκελο `books/`
(όχι στο Google Drive). Ό,τι βλέπεις online είναι ένα **στιγμιότυπο** του wiki.
Για να ενημερωθεί με νέα/αλλαγμένα βιβλία, πρέπει να ξανα-ανεβάσεις τον φάκελο.

## Βήμα-βήμα ανάπτυξη στο Render (δωρεάν)

### 1. Δημιούργησε λογαριασμό Render
- Πήγαινε στο https://render.com και φτιάξε δωρεάν λογαριασμό
- Σύνδεσέ τον με τον λογαριασμό σου στο **GitHub**

### 2. Δημιούργησε repo στο GitHub με αυτά τα αρχεία
Αν δεν έχεις GitHub: δημιούργησε λογαριασμό στο https://github.com, μετά
πάτα "New repository" (π.χ. όνομα `amorwiki`), και ανέβασε τα 4 αρχεία +
τον φάκελο `books/` (drag & drop μέσα από τον browser λειτουργεί, ή git).

### 3. Δημιούργησε Web Service στο Render
1. Στο Render: **New → Web Service**
2. Σύνδεσε το repo σου στο GitHub και διάλεξέ το
3. Οι προεπιλογές είναι σχεδόν σωστές:
   - **Runtime**: Python 3
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `python amorwiki_server.py`  (ή αφήνεις το Procfile)
   - **Instance Type**: Free
4. Πάτα **Create Web Service**

### 4. Περίμενε το deploy (~2-3 λεπτά)
Θα πάρεις μια διεύθυνση της μορφής:
```
https://amorwiki-xxxx.onrender.com
```
Αυτή είναι η μόνιμη διεύθυνση — άνοιξέ την από οπουδήποτε, σε όλες τις συσκευές.

### 5. (Προαιρετικό) Κωδικός επεξεργασίας
Στο Render, στο tab του service → **Environment** → πρόσθεσε:
```
AMORWIKI_PASSWORD=Ο-κωδικός-σου
```
Χωρίς αυτό, ο καθένας στο διαδίκτυο μπορεί να επεξεργαστεί/διαγράψει βιβλία.

## Σημειώσεις / Όρια δωρεάν tier
- ⏱️ Ο δωρεάν server «κοιμάται» μετά από ~15 λεπτά χωρίς επισκέψεις.
  Όταν ανοίξεις τη σελίδα, ξυπνάει σε ~30-60 δευτερόλεπτα.
  (Μπορείς να βάλεις ένα δωρεάν uptime-monitor π.χ. UptimeRobot να τον «χτυπάει»
  κάθε 10 λεπτά ώστε να μη κοιμάται ποτέ.)
- 💾 Ο δίσκος είναι **προσωρινός**: προσθήκες/διαγραφές βιβλίων από το web
  χάνονται όταν το Render κάνει redeploy ή restart.
  Για μόνιμη αποθήκευση χρειάζεται επί πληρωμή persistent disk,
  ή να ανεβάζεις τις αλλαγές ξανά στο GitHub.
- 📅 Για να ενημερώσεις τα βιβλία: αντικατέστησε τον φάκελο `books/` στο repo
  και το Render θα κάνει αυτόματα redeploy.
